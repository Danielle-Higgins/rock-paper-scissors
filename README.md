Wanna play rock, paper, scissors but don't have anyone to play with? Well why not battle with the computer? This project is built is part of the Odin Project Curriculum where I use JavaScript and DOM manipulation to make the game interactive for the player. This game was fun to build and if you like to play rock, paper, scissors, I hope you enjoy playing around with it!
